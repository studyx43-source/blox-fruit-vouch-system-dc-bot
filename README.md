# Tower Supplier Bot

Buy, Pre-Order and Support tickets with forms, PO/BUY IDs, staff claim/complete/cancel/close actions, JSON persistence, completed-deal records without client identity, vouches without amount/client fields, HTML transcripts, and pre-order stats for INR/LTC.

Setup: install requirements, copy .env.example to .env, add DISCORD_TOKEN, enable Members + Message Content intents, then run python main.py.


Use `$help` in Discord for the interactive command guide. Custom server emojis are configured in `config.json` and used where relevant.
